# Billapp.de

Erste funktionsfähige, serverlose Version zum Erstellen von Rechnungen.

## Funktionen
- Rechnungen erstellen, bearbeiten und löschen
- Speicherung im Browser (localStorage)
- automatische Netto-, MwSt.- und Brutto-Berechnung
- 19 %, 7 % oder 0 % MwSt.
- automatische Rechnungsnummern
- mehrere Positionen mit Menge und Einzelpreis
- Zahlungsziel und Hinweise
- Druckansicht für PDF-Export
- responsive Oberfläche
- Euro (€) und deutsche Formate

## Start
`npm test`
`npm start`

Danach http://localhost:8080 öffnen.

## Nächste Ausbaustufen
Backend/Datenbank, Benutzerkonto, serverseitige PDF-Erzeugung, E-Mail-Versand, DATEV-Export, Kundenverwaltung und revisionssichere Archivierung.
